# 遠隔操作 joy ルーティング仕様

遠隔操作PCの `racing_kart_manager` が、手元のジョイスティック入力を対象車両へどう配るかを定める。

- 実装: `manager/racing_kart_manager_core.py`（純ロジック）、`manager/racing_kart_manager.py`（ROS ノード）、`manager/racing_kart_manager_gui.py`（GUI）
- テスト: `manager/tests/`（§10 の観点に対応する）

## 1. 役割

manager は **joy の中継器**である。オペレータが GUI で選んだ宛先へ、joy をマスクして配る。

判断に使うのは次の2つだけ。

- GUI から届いた選択
- 受信した joy の中身

車両から届くテレメトリは購読しない（§9）。

## 2. 対象車両

- **REQ-01** 対象車両は起動引数で与える。既定値を持たない。
- **REQ-02** 空・未知の車両ID・重複を含む引数は解釈失敗とし、manager は起動しない。
- **REQ-03** 「全台」は対象車両の全部を指す。運用に存在する車両の全部ではない。

## 3. 選択

- **REQ-04** 選択は次の3状態のいずれか。**未選択** / **単車**（車両IDひとつ） / **全台**。
- **REQ-05** 起動直後は未選択。
- **REQ-06** 選択はいつでも即座に切り替わる。前提条件を課さない。joy の中身も、直前の選択も問わない。
- **REQ-07** 対象車両に含まれない車両IDを指定されたら無視する。選択は変わらない。
- **REQ-08** 解釈できないコマンドは無視する。選択は変わらず、例外を投げてはならない。
  manager が落ちると全車が joy を失い、5秒後に緊急停止がラッチする（§7）。落ちないことが安全性に直結する。

## 4. joy の送出

### 4.1 契機

- **REQ-09** joy を1つ受信するごとに、対象車両**全部**へ1つずつ publish する。タイマーでは送らない。
  joy が途絶えれば車両にも新鮮な joy が届かなくなり、車両側の5秒ウォッチドッグが働く。
  タイマー送出を入れると、この生存チェーンが切れる。
- **REQ-10** 未選択であっても送出する。宛先を止めない。
  送出を止めた車両は5秒後に緊急停止がラッチし、選択し直しても解除操作なしには動かせなくなる。

### 4.2 マスク

- **REQ-11** 送出する joy は axes 8 要素・buttons 11 要素とする。
- **REQ-12** 宛先が**選択車**（単車選択ならその1台、全台選択なら全部）なら、受信した joy をそのまま送る。
- **REQ-13** 宛先が**非選択車**なら、axes を無操作値（§5.1）に、buttons を 0 に置き換えて送る。緊急停止ボタン（REQ-15）だけは例外。
- **REQ-14** 受信した joy の axes / buttons が REQ-11 の要素数と異なるときは不正入力とみなし、**全宛先を非選択車として扱う**。緊急停止ボタンは読み取れた範囲で判定する。
  壊れた入力で操縦させない。ただし壊れていても緊急停止だけは通す。
- **REQ-15** `header.stamp` は受信した joy の値を引き継ぐ。

| 宛先 | axes | LB / RB / START / BACK | LSB / RSB | A / B / X / Y |
| --- | --- | --- | --- | --- |
| 選択車 | 素通し | 素通し | 素通し | 素通し |
| 非選択車 | 無操作値 | 素通し（§6） | 0 | 0 |

## 5. キーバインド

`racing_kart_interface` の `src/racing_kart_driver/src/keybind/joystick.hpp` の複製である。
別リポジトリのため import できない。変更するときは両方を直すこと。

### 5.1 axes（8要素）

アクセルとブレーキは **0.0 ではなく +1.0 が無操作**である。車両側は `clamp((1.0 - axes[i]) / 2.0, 0, 1)`
で踏み込み量を作るため、0 で埋めるとアクセル 50%・ブレーキ 50% を踏んだ扱いになる。

| index | 名前 | 無操作値 |
| --- | --- | --- |
| 0 | Steer | 0.0 |
| 1 | LeftStickVertical（未使用） | 0.0 |
| 2 | Brake | +1.0 |
| 3 | RightStickHorizontal（未使用） | 0.0 |
| 4 | RightStickVertical（未使用） | 0.0 |
| 5 | Accel | +1.0 |
| 6 | DpadHorizontal（ギア） | 0.0 |
| 7 | DpadVertical（ギア） | 0.0 |

### 5.2 buttons（11要素）

| index | 名前 | 車両側での意味 |
| --- | --- | --- |
| 0 | A | control_mode を MANUAL へ |
| 1 | B | 未使用 |
| 2 | X | control_mode を AUTONOMOUS_STEER_ONLY へ |
| 3 | Y | control_mode を AUTONOMOUS へ |
| 4 | LB | 緊急停止 |
| 5 | RB | 緊急停止 |
| 6 | START | 緊急停止 |
| 7 | BACK | 緊急停止 |
| 8 | （未使用） | |
| 9 | LSB | RSB との同時押しで緊急停止解除 |
| 10 | RSB | LSB との同時押しで緊急停止解除 |

## 6. 緊急停止

- **REQ-16** 受信した joy で LB / RB / START / BACK のいずれかが押されていたら、**対象車両の全部**へ、その4ボタンすべてを 1 にして送る。選択の状態を問わない。未選択でも送る。
- **REQ-17** 緊急停止を送るのは、押されている joy を受信している間だけ。manager は緊急停止を保持しない。
  保持は車両側が行う（§7）。`joy_node` は `autorepeat_rate=20.0` で押下中も送り続けるため、押している限り繰り返し届く。
- **REQ-18** 緊急停止ボタンが押されていても、axes のマスクは REQ-12 / REQ-13 のまま変えない。
- **REQ-19** 解除（LSB と RSB の同時押し）は他のボタンと同じ扱いとする。**選択車にだけ届き、非選択車には 0 が送られる**。
  全台を戻すときは全台選択にして解除する。1台ずつ戻すときは選択を切り替えながら解除する。

## 7. 車両側の前提

manager の設計は `racing_kart_driver` の次の挙動に依存する。

- **緊急停止はラッチする。** 4ボタンのいずれかが 1 の joy を1つ受け取った時点で保持され、LSB+RSB を受け取るまで解除されない。manager 側で保持や再送をしなくてよいのはこのため。
- **joy が5秒（`joy_delay_threshold`）届かないと緊急停止がラッチする。**
- **axes / buttons の要素数が 8 / 11 と一致しない joy は使われない。** 停止指令が出るだけで、緊急停止のラッチもされない。
- **control_mode が AUTONOMOUS のとき、アクセル・ブレーキ・ステアは Autoware の指令で上書きされる。** joy の軸は効かない。無操作値を送っても自動走行は止まらない。

## 8. ROS インタフェース

### 8.1 トピック

購読

| topic | 型 | QoS |
| --- | --- | --- |
| `/racing_kart/joy` | `sensor_msgs/Joy` | depth 1 |
| `/racing_kart_manager/command` | `std_msgs/String` | RELIABLE, depth 10 |

配信

| topic | 型 | QoS |
| --- | --- | --- |
| `/<VEHICLE_ID>/racing_kart/joy` | `sensor_msgs/Joy` | depth 1 |
| `/racing_kart_manager/status` | `std_msgs/String` | RELIABLE, TRANSIENT_LOCAL, depth 1, 5Hz |

`/<VEHICLE_ID>/racing_kart/joy` は zenoh ブリッジが車両側の `/racing_kart/joy` へ届ける。
車両IDの名前空間を付けるのは manager の役目である。

status を TRANSIENT_LOCAL にするのは、GUI を後から起動しても最新の選択が出るようにするため。

依存するメッセージパッケージは `sensor_msgs` と `std_msgs` だけとする。

### 8.2 command

```json
{ "schema_version": 2, "command": "select", "target": "A3" }
```

`target` は車両ID / `"all"` / `"none"`。

### 8.3 status

```json
{
  "schema_version": 2,
  "stamp_ns": 1755600000000000000,
  "selection": "A3",
  "vehicles": ["A2", "A3", "A7"],
  "joy_age_s": 0.05,
  "emergency_pressed": false
}
```

| キー | 内容 |
| --- | --- |
| `selection` | 車両ID / `"all"` / `"none"` |
| `vehicles` | 対象車両。起動引数の順を保つ（GUI のボタン並びに効く） |
| `joy_age_s` | 最後に joy を受信してからの秒数。一度も受信していなければ `null` |
| `emergency_pressed` | 直近に受信した joy で緊急停止ボタンが押されていたか |

## 9. GUI

- **REQ-20** ボタンは「未選択」「全台」、および対象車両1台ごとの選択。押すと command を publish する。
- **REQ-21** GUI は条件判断を持たない。押せないボタンは無い。
- **REQ-22** GUI は manager と別プロセスで動く。GUI が落ちても manager は joy を配り続ける。

## 10. 保証しないこと

次は manager の責任外とし、GUI にも表示しない。

- **車両が停止しているか、緊急停止中か、どの control_mode か。** テレメトリを購読しないため知り得ない。状態は RViz と車両側のログで確認する。
- **非選択車が走っていないこと。** 非選択車には無操作の joy が届くが、その車が AUTONOMOUS なら Autoware の指令で走り続ける（§7）。
- **全台選択中に1台だけを操作すること。** 全台選択中は軸もボタンも全車へ等しく届く。Y を押せば全車が同時に自動運転へ入り、アクセルを踏めば全車が同時に走る。
- **選択の切り替え時に急発進しないこと。** アクセルを踏んだまま切り替えれば、切り替え先はその踏み込み量で動き出す。
- **緊急停止が全車へ届いたことの確認。** 届いたかどうかは manager には分からない。
